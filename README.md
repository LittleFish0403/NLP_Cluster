# NLP_CLuster 简易文本主题聚类
## 功能
这段代码的主要功能是通过调用DeepSeek API来分析Excel文件中的文本内容，并根据预定义的关键词列表生成对应的标记结果，实现对文本的简单主题分类。
- 读取Excel文件中的文本数据
- 调用DeepSeek API进行文本分析
- 根据预定义的关键词列表判断文本中是否包含这些关键词
- 将分析结果(0/1标记)写入Excel文件的新列中

## 参数
需要config.py文件提供以下配置：
| 参数名        | 值/示例                                                                 | 说明                                                                 |
|---------------|------------------------------------------------------------------------|--------------------------------------------------------------------|
| `INPUT_FILE`  | `"input.xlsx"`                                                        | 输入Excel文件路径                                                  |
| `OUTPUT_FILE` | `"output.xlsx"`                                                       | 输出结果Excel文件路径                                              |
| `API_KEY`     | `"your_apikey"`                               | DeepSeek API密钥（示例值，实际使用时需替换）                       |
| `KEYWORDS`    | `["经济对比", "文化价值", "社会治理", "科技发展", "生态治理", "民生痛点", "历史叙事", "人际交往", "其他"]` | 9个预定义关键词，前8个不匹配时"其他"位自动标1                     |
| `URL`         | `"https://api.deepseek.com"`                                          | API基础地址                                                       |
| `TARGET`      | `("标题", "描述")`                                                   | 需要拼接分析的列名元组                                            |
| `PROMPT`      | 见config完整提示词                                                      | 标准化处理规则                                                    |

## 使用方法
1. 安装requirement.txt中的库
2. 获取所用大模型服务的apikey，替换config内的设置
3. 根据上述参数，修改config内的配置
4. 运行main.py
